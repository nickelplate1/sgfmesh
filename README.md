## Requirements
- Docker + Docker Compose

## Setup
1. git clone this repo
2. cp .env.example .env
3. Edit .env if needed
4. docker compose up -d

## Accessing
- MQTT broker: your-ip:1883
- Meshview: http://your-ip:8081

## Meshtastic Device Config
- Server: your-ip
- Port: 1883
- Uplink: enabled
- JSON: enabled
